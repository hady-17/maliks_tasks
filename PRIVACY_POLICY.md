## Information We Collect
We collect the following categories of information to provide the app’s task management features.

- Account Information
  - Name
  - Email address
  - User role (e.g., manager, team member)
  - Branch and section
- Tasks and Notes
  - Task titles, descriptions, assignees, status (created/completed), due dates, and task notes you create
- Device & Notification Data
  - Device push notification tokens (to send push notifications via FCM)
- App Logs and Diagnostics
  - Basic operational logs and error reports for troubleshooting and to improve reliability

We collect information you provide directly (for example, when you create an account or a task) and certain technical information automatically (like push tokens and logs).

## How We Use Your Information
We use collected information to:
- Provide, operate, and maintain the app and its features
- Authenticate users and apply branch-based access controls
- Store and sync tasks and task notes in real time within a branch
- Send push notifications about new tasks and overdue tasks
- Support account recovery, security, and troubleshooting
- Perform scheduled jobs and notification sending via our Node.js backend

We only use data for purposes compatible with the app’s task management operations.

## Third-Party Services
We use third-party service providers to deliver core functionality:
- Supabase — used for authentication, database storage, realtime updates, and row-level security (RLS). Supabase stores your account data, tasks, and related content.
- Firebase Cloud Messaging (FCM) — used solely to deliver push notifications to devices. We store device push tokens so FCM can deliver notifications.
- A lightweight Node.js backend — used only to trigger notifications and run scheduled jobs; it accesses the minimal data needed to send notifications.

These services have their own privacy and security practices. By using the app you agree that your data is processed by these providers as necessary to provide the service.

## Data Sharing and Disclosure
We do not sell or rent your personal information. We disclose personal data only in the following limited ways:

## Security
We take reasonable technical, administrative, and physical measures to protect data:
- Encryption in transit (TLS) for data sent between the app, Supabase, and our backend.
- Access controls limiting who can access data inside our service.
- Use of Supabase row-level security (RLS) to enforce branch- and role-based access.
- Limited access to device push tokens, used only to send notifications.

While we work to protect your information, no system is completely secure. We cannot guarantee absolute security.
